# Intro video (optional)

Drop your intro video here, named one of:

    intro.mp4   intro.webm   intro.mov   intro.m4v

If one exists, the app plays it (muted, autoplaying, with controls) in a "WELCOME.EXE" window
when someone opens the app, and an **Enter the app** button continues to the main screen.

If no file is here, the built-in pixel "Loading..." intro plays instead and removes itself
after about four seconds.

Tip: keep it short (under ~10 s) and under ~20 MB so it loads quickly. H.264 `.mp4` plays everywhere.
Set `SPEC_SKIP_INTRO=1` in the environment to switch the intro off entirely.
